# Complete release — October 9, 2026

The owner authorized deployment of all intentional workspace changes. The
release merges snapshot `bdecaced` onto production `4adfe02`, preserving newer
production integrations instead of replacing them with the older checkout.
`complete-release-reconciliation-2026-10-09.json` accounts for all 1,237 paths.

## User-facing changes

- Hook editing stays beside its preview, with one blank text box initially,
  independently timed additional text, compact actions and Back to preview.
- Schedule opens with both hook and demo previews, prepares any necessary
  edits and joins them in order. Posting still requires explicit confirmation.
- Slides contain owned generated/uploaded images. Catalogue slides guide
  layout; the Instructions plus button supplies a separate subject/style image.
- Save progress identifies preparation stages; media transfers run in bounded
  parallel batches. Existing durable retries and ownership checks remain.
- Plugin version 0.1.2 and its documentation/downloads accompany the release.

Current production download behavior, model-specific prompt policy, WAN/audio,
character, authorization, credit, publishing and recovery fixes are preserved.

Production Next.js build; 645 Explore tests; 310 worker tests; MCP unit,

Wall of Text, queue, scaling, AI edit, Trending, navigation, latency, scheduling

after updating stale navigation/component fixtures and removing a dependency
on a canary script absent from both baseline checkouts. App and worker production

These fixtures do not prove paid provider behavior on the hosted account.

## Rollout and exclusions

Deploy the same immutable worker image to the five worker services and two
worker jobs before promoting the matching website and MCP commit. Preserve
live environment values, secret references, queue allowlists and scheduler
states. No broad Terraform apply or migration replay belongs to this rollout:
the changed slideshow API uses the existing owned-media Library RPC, and all
release SQL files match the current production tree.

Excluded paths from the initial status audit:

- `scripts/__pycache__/build-ugc-pilot-plugin.cpython-313.pyc`: generated bytecode.
- `scripts/__pycache__/test-ugc-pilot-plugin-build.cpython-313.pyc`: generated bytecode.

Already ignored local environment files, dependency/build directories, caches,
temporary QA output, private infrastructure state and the integration checkout
remain local. Intentional source, configuration, migrations, scripts, tests,
documentation, plugin bundles and media assets are included.

The measured 119–190 second wait before worker claim remains an infrastructure
investigation. This release improves feedback and avoids redundant preparation;
it does not claim to eliminate the observed startup interval.
