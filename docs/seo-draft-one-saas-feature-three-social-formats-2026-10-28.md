# Draft: Turn one SaaS feature into hook-demo, talking-head and wall-text videos

**Unpublished planning draft.** Original evidence required before release: Three complete original assets using the same verified feature facts. Fictional examples are labeled; they are not actual customer outcomes.

## Choose one feature and one audience task

A format comparison is useful when each version explains the same verified product behavior in a distinct way. Start with a real feature, its conditions and the proof you can show. The example below is a fictional plan for a call note with a next-step section, not three finished assets.

## Plan a reaction plus demo

Opening text: “wait, the next steps are right here.” Follow with a real recording that opens the project note and holds the next-step section. End with the action “check the next step.” This format relies on a clear visible product reveal.

## Plan a wall-of-text video and slideshow

Wall-of-text overlay: “the call is over. the follow-up is tomorrow. open the project note and check the next step.” Pair it with calm permissioned footage. Slideshow: situation, why the action matters, open the note, find the section, and decide the next action. The first emphasizes a written thought; the second gives distinct slide beats.

## Compare completed assets carefully

Create each asset only with accurate facts, approved footage and readable text. Keep the same product promise and intended action if comparing formats, and record actual audience, timing and platform metrics. Do not call these plans actual assets or declare a winner without real evidence.
