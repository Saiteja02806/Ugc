# Workflow dark-theme study — 10 October 2026

The user chose the first unified-brief image as the preferred starting point,
but reported that it still felt uncomfortable. They requested a black/dark
theme of that specific image to help judge it.

This is one controlled image revision. The attached user image was viewed
and supplied directly to the built-in image_gen tool as the edit target.
No application code, global theme preference or production behavior changed.

Asset: [Dark unified brief](../../output/imagegen/workflow-unified-brief-dark.png)

## Theme intent

Near-black canvas #08090B; header #0E1013; workspace #15171B;
reference controls #1B1E23; field wells #101216; outlines #3A414D;
main text #F0F2F6; secondary text #AAB3C1; brand orange #F5774E.

The aim is to compare the same composition with less bright surface area.
Dark mode is the user's requested direction, not a claim that every novice
prefers it or performs better with it.

## Visual review

The output retains the source choice, three optional references ABOVE the
brief, creator photograph, writing area, output controls and estimate/action
footer. Labels are readable in the generated image and the composition fits
the canvas without visibly clipped controls.

The reference area still uses substantial vertical space. Its size is a
possible contributor to the user's discomfort; this remains a design
hypothesis. A later refinement could shorten the attachment wells while
preserving the requested top placement. That layout refinement was not
folded into this theme comparison.

All example inputs, model choices and the 10-credit estimate remain
illustrative. This image is not an interactive or accessibility acceptance
test.
