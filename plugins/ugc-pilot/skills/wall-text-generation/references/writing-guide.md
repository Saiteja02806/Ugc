# Business-specific wall copy

The supplied Wall of Text Generation file is a collection of creator transcriptions. It remains intact outside the installable package. These instructions turn the intended format into a writing workflow; the creator transcripts are not templates to copy or evidence for a customer's claims.

| Format | Structure |
| --- | --- |
| Paragraph | Relatable situation → specific tension → feature or practical shift → optional next step |
| Stacked list | Opening premise → 3–5 related items → one takeaway |
| POV story | Recognizable audience moment → complication → truthful discovery or question |
| Contrast | Prior process → friction → demonstrable alternative, without fabricated metrics |
| Short statement | One observation or question when the user wants sparse copy |

For a local bakery taking pre-orders online, a grounded draft could say: “The hardest part of a busy morning can be deciding what to order while everyone is waiting. If you already know your usual pastry, check the bakery's pre-order menu before you leave. Pick what you want and follow the collection instructions, so your morning starts with a plan.” Use this only if online pre-ordering is supplied as a real feature; do not invent queue-skipping or guaranteed preparation times.

If a user says a planner “helps organize tasks,” describe grouping tasks or planning a day only if that functionality is supplied. Avoid “this saved me ten hours” without a real attributed result. With sparse context, a direct question or scenario can be specific without claiming proof.

Use purposeful line breaks for a stacked list and ordinary sentences for a paragraph. Keep Unicode and emoji literal. A director receives the selected finished string, not a rewritten summary. Reading time depends on language, layout and audience; English word-count estimates are heuristics and should not govern other scripts mechanically.
