unchanged by the carousel presentation work.

`.tmp/release-20261001` checkout and merges production main
`7cd0a46a50765d3b99d9705969ce20f0fb2a12e9`. Newer production video-reference/audio,
quality, history and recovery behavior is retained rather than replaced with older
local implementations. The validated MCP source from the separate production
audit is included; its dedicated Vercel deployment is not changed by this website
release. MCP V1 collections remain image/video/influencer, separate from website
audio references, and owner-scoped filtering happens before pagination.

## Deployment order and acceptance gates

1. Temporarily suppress automatic Vercel Git builds, push the validated source.
2. Apply only the missing `allow_wall_text_v13_50px_typography` migration.
   Already-applied MCP, Higgsfield, audio-reference and email rate-limit migrations
   are not replayed solely because local filenames have different timestamps.
3. Restore the previous Vercel build-ignore setting and deploy the exact Git SHA.
4. Build one GCP worker image with the same SHA, deploy all five active worker
   services and the video-render/replenishment jobs, preserving resource/IAM/queue
   settings. Explicitly enable approved TikTok Direct Post on the publish worker.
   Do not deploy unrelated Tinder or one-off canary resources or resume a paused
   Carousel scheduler.
5. Verify source/digest parity, public production pages and auth safety, signed-in
   platform visibility/Carousel preview if an existing session is available, and
   bounded runtime logs.

Email verification/reset real-inbox acceptance requires an owner-approved mailbox;
no customer password, connected account or scheduled post is changed by the smoke
test. The corrected reset-template draft still needs the previously documented
owner approval; the existing published template is preserved. Paid generation and
actual third-party publication are not included in this deployment smoke test.
